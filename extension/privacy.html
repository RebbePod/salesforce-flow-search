Salesforce Flow Search
Privacy Policy

Effective October 5, 2026. Applies to version 1.0.0.

Salesforce Flow Search helps you find flows in supported Salesforce lists. It processes the page content needed for that feature locally in your browser. It does not send your Salesforce list content or search text to the extension's publisher.

Information handled locally

The extension reads loaded Flow-list cells, headings, list status, and the current Salesforce page path/domain to identify a supported list, filter rows, and control loading. Cells can include Flow names, API names, process types, dates, and names shown under Last Modified By. Your search text and selected columns are used in memory for the current page.

Saved preferences

Automatic loading, initial search scope, and allowed page paths are stored using Chrome's local extension storage. They apply across tabs in the same browser profile. The extension does not use Chrome Storage Sync and does not save a copy of your Salesforce records, search text, or browsing history.

Network activity and third parties

No analytics, advertising, developer-server uploads, Salesforce API calls, credential extraction, or remote executable code are included. Loading additional rows scrolls Salesforce's existing list. Salesforce may then make its normal authenticated requests using your existing session; those requests and Salesforce's handling of your account are governed by Salesforce's policies. The extension does not sell or share your locally processed page data.

Local diagnostics

Technical status can be inspected locally for troubleshooting, including extension version, domain category, table headings, row counts and extension errors. It is not uploaded automatically and does not include a list of record values. Browser console messages may show extension errors. Do not include confidential Salesforce information in support messages.

Retention and control

Page content, search text and selected columns remain in memory for the current page and are not persisted by the extension. Saved preferences remain until changed or the extension is removed. You can edit allowed paths, disable automatic loading, disable the extension, or uninstall it. Removing the extension removes its local extension storage in that Chrome profile.

Support

If you choose to email support, the publisher receives the email address, message, and attachments you provide and uses them to respond to your request. Email handling is separate from the extension's local processing and is subject to the email service's policies.

Limited use and changes

The extension's use of user information follows the Chrome Web Store User Data Policy, including its Limited Use requirements. Information is used only for the stated Flow-search purpose, not advertising or credit decisions. This page will be updated if the extension's data practices change.
