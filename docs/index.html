Salesforce Flow Search

Find the flow.
Skip the hunt.

Search the columns in your loaded Salesforce Flow list, narrow results to selected columns, and control loading with a compact toolbar.

Search your way

Start with all columns, Flow name only, or Flow name and API name. Use the dropdown to narrow the same text to one or several columns. Preferences save across your tabs.

Search covers loaded rows. API names must be available in the list. Automatic loading scrolls the current list and can be stopped or resumed.

Local processing

List content and search text are processed in your browser. Only preferences are saved. No analytics, advertising, developer-server uploads, or Salesforce API calls are included.
